# 五轴电机操作页面（第一阶段）

本页面是 `MotorDemoRuntime` 之上的薄适配层，与 `五轴电机实验CLI.md` 共用同一套后端、校准、录制文件和安全边界。页面在实体动作验收之前完成，因此**默认离线模拟，不会打开串口**；网页测试与离线预检不能证明实体动作、碰撞、负载或承重已经通过。

```bash
PYTHONPATH=ailamp_runtime python3 -m ailamp.motor_web
```

启动后在浏览器打开终端打印的地址（默认 `127.0.0.1:8766`）。页面只用标准库和内联 HTML/JS，不加载任何外部资源，Nano 无外网时同样可用。

## 页面控件

| 控件 | 调用 | 说明 |
| --- | --- | --- |
| 连接（只读） | `connect` | 只读连接并检查校准、原始位置、扭矩和模式；不会自动 arm |
| Arm… | `arm` | 弹出确认面板：填写 Goal_Velocity / Acceleration / Torque_Limit，勾选"我确认机构已被支撑"，输入 `CONFIRM`。三个数值不预填，占位符只显示软件边界，不是承重配置 |
| 捕获 home… | `capture-home` | 同样的确认门；把当前实测姿态保存为真实 home |
| 动作按钮 | `play <name>` | 按录制目录里的 CSV 逐个生成，每个动作独立触发 |
| 完整剧本 | `script` | 默认剧本 `wake_up → nod → curious → shy → headshake → scanning → happy_wiggle → home`；缺任一录制文件会在启动前拒绝 |
| 归位（home） | `home` | 需要先捕获 home，且 home 文件的校准 SHA-256、机器人 ID、关节映射必须匹配 |
| 停止（取消后续帧并保持，不断电） | `stop` | 取消后续帧，由唯一发送 worker 新读实测位置并保持；**不会卸力，也不是物理断电急停** |
| Release… | `release` | 同样的确认门；只有确认机构已被支撑后才卸力 |
| 令牌输入框 | — | 非 loopback 访问时填写控制令牌，只存在当前标签页会话中 |

按钮可用性完全由 runtime 状态推导：未连接只能"连接"；已连接未 arm 只能"Arm"；已 arm 且空闲才能触发动作、剧本、归位、捕获 home 和 release；"停止"在已 arm 时始终可用，包括忙碌中。

## 状态与事件

页面每 500 ms 轮询一次 `/api/state`，显示连接、arm、扭矩状态、当前任务、位置来源、五个关节的指令值与实测反馈（归一化 `[-100, 100]`），以及最近 50 条事件。`sent`、`feedback_reached`、`operator_confirmed` 含义不同，不能互相替代。

一旦 runtime 锁定故障，页面顶部会固定显示红色故障面板，所有动作按钮禁用，并提示"故障已锁定，程序不会自动重试；请先人工确认机构与供电状态，然后重启进程"。页面本身不做任何重试。

## 请求被拒绝时

- `400 invalid_request`：字段缺失、未知字段、类型不对、确认字符串不是 `CONFIRM`、录制名不存在。请求没有到达 runtime。
- `409 runtime_refused`：runtime 的安全拒绝原样返回，例如未连接、未 arm、忙碌、故障锁定、home 未捕获、校准不匹配。
- `403 forbidden`：Host/Origin 不匹配、CSRF 令牌缺失或控制令牌错误。

## 真实硬件模式

只能由现场主操作者显式选择，并且必须显式传入专用 `--home-path`；缺失时会在加载后端或绑定端口之前拒绝启动：

```bash
PYTHONPATH=ailamp_runtime python3 -m ailamp.motor_web --hardware --home-path output/five_axis_demo_home.hardware.json
```

真实模式下页面顶部横幅变为红色"实机模式：会写入真实电机"。流程仍是先"连接"，再按现场顺序单独"Arm"。同一时刻只允许一个进程占用电机总线；不要同时运行 CLI 和页面。

## 从另一台机器访问

页面默认只监听 `127.0.0.1`。要从 Mac 访问 Nano 上的页面，必须指定 Nano 的具体 IPv4 地址，并在环境变量 `AILAMP_MOTOR_WEB_TOKEN` 中提供至少 32 字符的控制令牌；通配地址 `0.0.0.0` 会被拒绝：

```bash
AILAMP_MOTOR_WEB_TOKEN='<至少32字符>' PYTHONPATH=ailamp_runtime python3 -m ailamp.motor_web --host 192.168.55.1
```

浏览器端在"令牌"输入框填入同一个值。令牌只从环境变量读取，不接受命令行参数，也不要写进仓库。

## 退出

Ctrl-C 或 SIGTERM 会先尝试正常 stop-and-hold，再关闭连接；关闭使用 `disable_torque=False`，不会静默卸力。若扭矩仍可能使能，退出时会打印警告：退出后程序不再监测。

本页面的数值边界与 CLI 一致：`fps` 在 `(0, 30]`，`max-step-units` 在 `(0, 4]`，`feedback-tolerance` 在 `[0, 5]`，`feedback-timeout` 在 `(0, 30]` 秒，`feedback-poll-interval` 在 `(0, 1]` 秒；`--http-port` 在 `[0, 65535]`。这些只是当前实验软件边界，不是电机额定承载、碰撞安全或物理安全证明。

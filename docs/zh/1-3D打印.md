# 1. 3D 打印

使用 `3D/` 目录中的 LeLamp 原始 `.3mf` 文件。

## CAD 建模来源

AILamp 保持原 LeLamp 的机械建模流程：

- 主 CAD 软件：OnShape。
- 原始 CAD 链接：`https://cad.onshape.com/documents/16c9706360b5ad34f9c8db49/w/2edfa54c83253c120fbc9e58/e/a7196194821d9cfe2842a44a`
- 原始装配链接：`https://cad.onshape.com/documents/16c9706360b5ad34f9c8db49/w/2edfa54c83253c120fbc9e58/e/a35eec618cd78ea5d74bf01b`
- 3D 打印导出格式：`.3mf`。
- 仿真网格导出格式：`.stl`。

AILamp v1 不把 Blender、SolidWorks、Fusion 360、FreeCAD 作为主建模流程。

需要打印：

```text
LampBase.3mf x1
LampBase - Cover.3mf x1
LampArm (Base-Elbow).3mf x1
LampArm (Elbow-Wrist).3mf x1
LampArm (Pitch).3mf x2
LampHead.3mf x1
LampHead - Diffuser.3mf x1
```

## AILamp 替换底座套件

AILamp v1 保留 LeLamp 原始 7 个 `.3mf` 文件作为参考。当前选择 Jetson Orin Nano Super 后，不要把原始 `LampBase.3mf` 和 `LampBase - Cover.3mf` 作为最终打印件，而是打印 AILamp 替换底座壳体和替换上盖。

尺寸校核：当前按 Jetson Orin Nano Super 开发套件 103 x 90.5 x 34.77 mm 外包络建模，载板本体按 100 x 79 mm 处理。Raspberry Pi Pico WH 按 51 x 21 mm，Waveshare Servo Driver with ESP32 按 65 x 30 mm。原 LeLamp `LampBase.3mf` 外形约为 160 x 190 x 40 mm，所以 AILamp 替换底座扩大到 220 x 300 x 66 mm，同时优先保留完整的中部电机仓和灯臂根部关系。

外形构建方式：本版本不是新增第二个外部底座，而是生成替换版 LampBase 壳体和上盖。壳体、上盖和过渡靴都由圆角矩形多边形生成，并带有壳壁、下沉 lip、螺丝柱、散热口和服务开口。中部电机仓先完整避让，Orin 开发板放在前方电子仓，Pico WH 和 ST3215 驱动板放在后方电子仓。

| 适配件文件 | 数量 | 用途 |
| --- | ---: | --- |
| `AILamp_LampBase_Electronics_Shell.3mf` | 1 | 替换版 LampBase 壳体，容纳 Jetson Orin Nano Super、Pico WH、ST3215 驱动板、走线和散热空间 |
| `AILamp_LampBase_Electronics_Cover.3mf` | 1 | 替换版 LampBase 上盖，带凸起灯臂固定座、固定孔和检修通风孔 |
| `AILamp_Base_Arm_Link_Boot.3mf` | 1 | 固定上盖与运动灯臂根部之间的随动过渡靴 |
| `AILamp_Cable_Clip_6mm.3mf` | 2-4 | USB 和信号线走线 |
| `AILamp_Cable_Clip_10mm.3mf` | 2-4 | 电源线和舵机线走线 |
| `AILamp_Jetson_Orin_Base_Tray.3mf` | 可选 | 台架调试用 Orin 外置托盘 |
| `AILamp_Electronics_Side_Deck.3mf` | 可选 | 台架调试用 Pico WH 和 ST3215 驱动板侧板 |

每个适配件 `.3mf` 都有同名 `.stl` 导出文件，用于切片软件兼容和外形检查。

替换底座几何关系：

- 替换壳体外形：220 x 300 x 66 mm。
- 替换上盖板体：220 x 300 x 5.5 mm，包含凸起底座-灯臂固定座后的总高度为 22.5 mm。
- Orin 散热/线缆高度预留：34.77 mm 开发板总高 + 18 mm 插头弯折余量 + 6 mm 顶部空气层 = 58.77 mm，底座内部高度为 63 mm。
- 电机仓避让：中部 104 x 118 mm 先完整留给底座舵机和灯臂根部，不在这个区域放开发板定位柱。
- 散热和服务开口：底壳 Orin 散热区有 96 x 68 mm 底部进风窗，后侧有 82 x 12 mm 检修开口。上盖有 118 x 16 mm 前侧 I/O/调试口、Orin 区上方 118 x 8 mm 服务通风口、后侧电源/信号线束槽，以及左右 USB 摄像头/音频服务槽。
- 下层检修通过孔：78 x 94 mm。
- 凸起灯臂固定座：112 x 124 x 20 mm，中间给底座舵机/灯臂根部预留 72 x 86 mm 宽松避让。
- 灯臂固定座孔位：x 方向 +/-44 mm，y 方向 +/-50 mm。
- 随动底座-灯臂过渡靴：84 x 84 x 45 mm，中间预留 48 x 54 mm 宽松避让。MuJoCo 中这个过渡靴挂在原 LeLamp 上盖 transform 上，会跟随灯臂根部，而不是跟固定电子仓壳体绑定。
- 上盖与壳体固定孔位：x 方向 +/-96 mm、y 方向 -106 mm 和 +166 mm。Y 方向非对称是为了保留原 LeLamp 灯臂原点关系，同时把电子仓向前扩展。
- Orin 内部定位：116 x 104 mm 宽松边缘限位柱，围绕 103 x 90.5 mm 开发套件外包络。它们是边缘限位和绑带/螺丝固定点，不声称穿过 Orin 载板孔位。
- Waveshare 驱动板定位柱：58 x 23 mm 孔位，对应驱动板固定孔距。

当前替换底座版本不要打印或安装灯头适配件。摄像头、灯板和音频硬件先按线缆/设备接入处理；底座上盖已经预留对应线缆服务槽，灯头/外壳固定件需要等实物线缆弯折半径确认后再单独做适配。

尺寸规则：第一版适配件不要卡太死。PCB 口袋和板边限位都故意预留间隙，线缆出口至少额外预留 2.5 mm，固定优先使用螺丝、扎带或可拆绑带，不依赖硬卡扣挤压板子。

隐藏电子件路线优先低填充打印 `AILamp_LampBase_Electronics_Shell.3mf`、`AILamp_LampBase_Electronics_Cover.3mf` 和 `AILamp_Base_Arm_Link_Boot.3mf` 做试装。它们在 AILamp 装配中替代原 LeLamp 底座和上盖。

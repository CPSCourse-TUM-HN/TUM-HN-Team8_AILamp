## 操作系统与运行时

```text
Jetson Nano OS -> NVIDIA JetPack 4.6.x / Jetson Linux R32.x，基于 Ubuntu 18.04
推荐首次刷机 -> JetPack 4.6.1 Jetson Nano Developer Kit SD card image
Python 运行时 -> 单独安装 Python 3.11 virtual environment，不使用 Ubuntu 18.04 系统自带 Python 作为项目运行时
AILamp 安装 extra -> pip install -e ".[nano]"
视觉 -> USB UVC 图像帧 + OpenAI API-hybrid
仿真 -> MuJoCo 只在 Mac/PC 上运行，不在 Jetson Nano 上运行
```

这会替代上游 LeLamp 的 Raspberry Pi OS 流程。Jetson Nano 版本不使用 Raspberry Pi OS、Pi Camera 库，也不需要 ReSpeaker 2-Mics Pi HAT 的 device-tree overlay。

## 电源域

```text
Jetson Nano 5V 4A barrel 电源 -> 只给 Jetson
GST120A12-P1J -> Waveshare Servo Driver with ESP32 -> 5x ST3215
GST60A05-P1J -> Adafruit NeoPixel NeoMatrix 8x8
Jetson USB -> Pico WH 控制信号，不给 LED 供电
```

## 默认端口

```text
/dev/ttyACM0 -> Waveshare 舵机驱动板
/dev/ttyACM1 -> Raspberry Pi Pico WH
/dev/video0  -> Arducam UB0234
USB audio    -> 未来可选升级，当前默认配置不安装
```

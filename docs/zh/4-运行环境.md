# 4. 运行环境

## Jetson Nano 操作系统

使用 NVIDIA Jetson Nano Developer Kit 4GB 的软件栈，不再使用上游 LeLamp 的 Raspberry Pi OS 软件栈。

```text
目标开发板 -> NVIDIA Jetson Nano Developer Kit 4GB, MPN 945-13450-0000-100
目标系统 -> NVIDIA JetPack 4.6.x / Jetson Linux R32.x，基于 Ubuntu 18.04
推荐首次刷机 -> JetPack 4.6.1 Jetson Nano Developer Kit SD card image
供电 -> 5V 4A barrel jack，5.5mm x 2.1mm，中心正极，插上 J48 jumper
```

不要安装 Raspberry Pi OS、Pi Camera 软件包或 ReSpeaker HAT overlay。当前 AILamp 配置没有麦克风，也没有扬声器。

## 安装 AILamp Runtime

先运行只读环境诊断：

```bash
scripts/check_jetson_nano_environment.sh
```

真机输出优先复用已经能播放 LeLamp 动作的 Python 环境。AILamp 本身支持 Python >=3.11 做软件预览，但本仓库旁边的上游 LeLamp runtime 目前要求 Python >=3.12，所以不要盲目重建 Python，也不要覆盖已有舵机校准。

```bash
cd ~/projects/AILamp
source /path/to/working/lelamp-env/bin/activate
pip install -e ".[nano,test]"
```

Nano extra 只安装 OpenAI/API-hybrid、USB 摄像头和串口支持；不安装 LiveKit、sounddevice、本地 YOLO pose、MuJoCo 或本地大模型。

## 配置

当前活动配置是 `config/hardware.toml`。真机输出前确认：

```text
motors.lamp_id -> 已经成功播放动作的准确 LeLamp follower ID；默认 "ailamp" 只是占位默认值
motors.port -> ST3215 控制板串口
led.port -> Pico WH 串口
camera.device_path -> Arducam USB UVC 设备
```

模型密钥只通过环境变量提供：

```bash
export OPENAI_API_KEY=...
```

## 检查

安全离线检查：

```bash
ailamp runtime-check --offline
ailamp hardware-check
```

Jetson 接线后：

```bash
ailamp runtime-check --include-motor-runtime
ailamp hardware-check --include-devices
ailamp camera-test
ailamp led-test
ailamp motor-test
```

`runtime-check --include-voice` 会报告当前配置故意禁用 voice/audio。`audio-test` 会先给出 audio-disabled 提示，不会导入 `sounddevice`。

`ailamp motor-test` 只列出配置端口和 bundled recordings，不移动硬件，也不证明真实动作通过。

## Pico WH 固件

把 `firmware/pico_led_controller/code.py` 复制到 Pico WH 的 CircuitPython 盘。

```text
Raspberry Pi Pico WH 使用 CircuitPython 9.x
/lib 中放入 adafruit-circuitpython-neopixel 库
NeoMatrix 数据线接 Pico GP0
Pico GP0 与 NeoMatrix DIN 之间使用 TXS0108E 电平转换
```

串口协议：

```text
PING
CLEAR
SOLID r g b
BRIGHTNESS value
PIXELS r,g,b;r,g,b
```

## 当前控制路径

先启动 dry-run：

```bash
ailamp web-control
```

再启用 OpenAI brain，不开摄像头：

```bash
OPENAI_API_KEY=... ailamp web-control --brain
```

再加入摄像头上下文：

```bash
OPENAI_API_KEY=... ailamp web-control --brain --vision
```

只有在已有 LeLamp 实物动作仍正常、LED 协议已验收、串口与 follower ID 已核对，并准备好有人看护的实物测试后，才启用真实输出。`motor-test` 的配置列表不能代替这一步：

```bash
OPENAI_API_KEY=... ailamp web-control --brain --vision --with-outputs
```

真机输出前，先停止原 LeLamp playback、`vision-loop` 或 voice-agent 等可能占用舵机串口的进程。浏览器里还必须显式解锁真机输出，命令才会发送到硬件。优先用 SSH tunnel 访问本机绑定的服务；如果绑定到局域网地址，必须使用具体的 Nano LAN IPv4 地址，设置强 `AILAMP_CONTROL_TOKEN`，并且只在可信网络中使用。
